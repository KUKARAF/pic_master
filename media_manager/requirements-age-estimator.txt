# Dependencies for the experimental age/gender estimator (MiVOLO) — see
# media_manager/age_estimator.py and age_estimator_worker.py.
#
# These MUST be installed into a SEPARATE, isolated virtualenv (not the main app's
# .venv): MiVOLO hard-pins an old ultralytics/timm that conflict with this app's own
# YOLO-World object detector and CLIP indexer (confirmed: installing mivolo into the
# main venv broke `from ultralytics import YOLOWorld`).
#
# Preferred setup: `media age-setup` — creates the venv at
# ~/.local/share/media_manager/age-venv and installs this file into it (see
# setup_age_venv in age_estimator.py). Manual equivalent from a repo checkout:
#   uv venv --python 3.12 .age-venv
#   uv pip install --python .age-venv/bin/python 'setuptools<81' wheel
#   uv pip install --python .age-venv/bin/python --no-build-isolation-package mivolo \
#       --extra-index-url https://download.pytorch.org/whl/xpu \
#       -r media_manager/requirements-age-estimator.txt
# Python 3.12 because these torch wheels have no 3.14+ builds; the setuptools<81 +
# no-build-isolation dance because MiVOLO's setup.py imports pkg_resources, which
# modern setuptools no longer ships.
#
# torch/torchvision: the +xpu builds so MiVOLO runs on the Intel Arc (B70,
# Battlemage) GPU. Battlemage needs torch >= 2.6 for XPU (2.5.x's XPU runtime
# doesn't cover it), so we can't use the older 2.5.1 that MiVOLO nominally
# prefers. These come from the PyTorch XPU index (see setup_age_venv in
# age_estimator.py, which adds --extra-index-url https://download.pytorch.org/whl/xpu).
# Two torch>=2.6 gotchas MiVOLO/old-ultralytics hit, and how they're handled:
#   * torch.load now defaults weights_only=True → age_estimator_worker.py sets
#     TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1 before importing torch to restore the old
#     behavior for the pinned checkpoints.
#   * mivolo.model.create_timm_model can break against a too-new timm — MiVOLO's
#     own pin is relied on; if it ever fails, pin a compatible timm here.
# NOTE: this torch bump for B70 is unverified against MiVOLO's model build — needs
# a validation run on the GPU box (see README's Intel Arc note).
torch==2.7.1+xpu
torchvision==0.22.1+xpu
opencv-python
numpy
transformers
accelerate
mivolo @ git+https://github.com/WildChlamydia/MiVOLO.git
